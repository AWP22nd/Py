# Tic Tac Toe Game (Python)

A simple command-line Tic Tac Toe game where you can play against another player or against an AI (using Minimax algorithm).

## Files
- `main.py`: Contains the game logic and AI.
- `requirements.txt`: (empty, no external dependencies needed)

## How to Run
1. Ensure you have Python 3 installed.
2. Navigate to the project directory.
3. Run.
4. Follow the prompts:
   - Choose game mode: `1` for Player vs Player, `2` for Player vs AI.
   - Enter your move as a number 1-9 corresponding to the board positions:
     ```
     1 | 2 | 3
     ---------
     4 | 5 | 6
     ---------
     7 | 8 | 9
     ```

## AI Difficulty
The AI uses the Minimax algorithm and plays optimally; it will never lose (can force a draw or win if you make a mistake).

Enjoy!
