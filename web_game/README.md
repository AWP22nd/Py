# Block Blast - Web Game

A fun and interactive web-based version of Block Blast, built with HTML, CSS, and JavaScript.

## How to Play

1. **Controls:**
   - **← Arrow**: Move piece left
   - **→ Arrow**: Move piece right
   - **↓ Arrow**: Move piece down
   - **↑ Arrow**: Rotate piece
   - **Space**: Drop piece instantly

2. **Objective:**
   - Clear lines by filling complete rows across the 10x20 grid
   - The game gets faster as you clear more lines
   - Score points for each line cleared

3. **Scoring:**
   - 1 line: 100 × level points
   - 2 lines: 300 × level points
   - 3 lines: 500 × level points
   - 4 lines: 800 × level points

## Features

- Interactive Tetris-style piece rotation and movement
- Score tracking with level progression
- Visual feedback with sparkles when lines are cleared
- Smooth animations and hover effects
- Responsive design for mobile devices
- Next piece preview

## Technology Stack

- HTML5 for game structure
- CSS3 for styling and animations
- Vanilla JavaScript for game logic

## Running the Game

Simply open `index.html` in any modern web browser. The game will start automatically with a new piece ready to play.
